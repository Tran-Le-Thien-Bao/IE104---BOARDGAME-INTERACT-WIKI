## Tìm ảnh
```
An Bình Tìm từ game 1- 50
Phúc Bảo (UIT)  Tìm từ game 51-100
Yến Nhi TÌm từ game 101-150
Mọi người tìm ảnh sẽ tìm 2 tấm mỗi bộ
1 cái ảnh bìa 600x800 px
1 cái ảnh nền 1600x1000 px
Định dạng ưu tiên Webp, png hay jpg cũng được vì đưa lên cũng đổi thành định dạng webp
Tạo xong để vô asset rồi push lên nhá.
```
